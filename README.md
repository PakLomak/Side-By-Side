# YouTube / Twitch Sync Compare

Инструмент для покадрового сравнения двух записей забегов (спидранов) бок о бок — с синхронным управлением, точным подсчётом времени по кадрам и генерацией Mod Note для верификации результата.

Работает как чисто фронтенд-страница: HTML + CSS + JS без сборки и зависимостей (кроме официального Twitch Embed API, который подключается прямо в `index.html`).

## Возможности

- **Два источника видео** — YouTube, Twitch (VOD, клип или канал в прямом эфире) или локальный файл. Достаточно вставить ссылку и нажать «Открыть», тип источника определяется автоматически.
- **Синхронное управление** — общие Play / Pause / Stop и перемотка ±10 секунд действуют на оба видео сразу.
- **Покадровая модель времени** — время видео считается через номер кадра и FPS (`frame → frame / FPS → время`), а не напрямую через `currentTime`, что даёт более точный и стабильный отсчёт.
- **Индивидуальная перемотка** — по кадрам и по секундам (10s / 30s / 1m / 2m / 5m) для каждого видео отдельно.
- **Быстрые переходы к старту/финишу** — кнопка ■ (Stop) под каждым видео возвращает к зафиксированному началу забега, а кнопка ⏭ рядом с полем End — к зафиксированному концу (появляется после того, как конец отмечен кнопкой 🏁).
- **Шкала перемотки** с отметками старта и финиша по каждому видео.
- **FPS**:
  - для локального файла определяется автоматически через `requestVideoFrameCallback`;
  - для Twitch подтягивается из метаданных выбранного качества потока (`getQualities()` отдаёт `framerate` для каждого варианта) и обновляется при ручной смене качества;
  - для YouTube вводится вручную — официальный iframe API не отдаёт эту информацию (см. «Известные ограничения»).
- **Качество видео**:
  - для Twitch можно переключать по-настоящему (через `Twitch.Player.setQuality`);
  - для локального файла показывается реальное разрешение файла;
  - для YouTube отображается «Auto (YouTube)» — управлять качеством через API нельзя (см. ниже).
- **Mod Note** — для каждого видео формируется строка вида
  `Mod Note: Start Time: 19.983, End Time: 1:44.383, Frame Rate: 60, Time: 1:44.383`
  с кнопкой «Copy» для вставки в верификацию забега.
- **Театральный (полноэкранный) режим** — оба видео растягиваются на весь экран, снизу остаётся плавающая панель с таймерами и общим управлением.
- **Режим одного видео** — кнопка в левом верхнем углу циклически показывает: оба видео → только Видео 1 → только Видео 2 → снова оба. Удобно, когда нужно спокойно посчитать конкретный забег.
- **Поделиться ссылкой** — кнопка 🔗 в центре рядом с общим управлением копирует ссылку, которая хранит в себе оба видео, время старта и финиша (если зафиксирован) и FPS каждого из них. При переходе по такой ссылке оба видео открываются автоматически с уже выставленными временем и FPS — не нужно настраивать всё заново.
- Адаптивная вёрстка для узких экранов.

## Структура проекта

```
index.html   разметка страницы
style.css    вся стилизация, включая театральный режим и режим одного видео
script.js    вся логика: плееры, синхронизация, шкалы, FPS/Quality, Mod Note
```

Всё лежит в трёх файлах без модулей и сборки — можно редактировать напрямую.

## Запуск

Открыть `index.html` напрямую через `file://` не получится — YouTube iframe API и Twitch Embed API используют `postMessage` и требуют реального origin. Нужен локальный HTTP-сервер, например:

- расширение **Live Server** в VS Code (правый клик по `index.html` → «Open with Live Server»);
- или из терминала: `python3 -m http.server 5500`, затем открыть `http://127.0.0.1:5500`.
- отлично работает на github.io https://paklomak.github.io/Side-By-Side/

## Как пользоваться

1. Вставить ссылку на YouTube (`youtube.com/watch?v=...` или `youtu.be/...`) или Twitch (VOD, клип или просто `twitch.tv/канал` для прямого эфира) в поле нужного видео и нажать «Открыть». Либо нажать 📁 и выбрать локальный файл.
2. При необходимости поправить FPS вручную и выставить время старта/финиша.
3. Управлять воспроизведением через общие кнопки в центре или через плавающую панель в театральном режиме.
4. Нажать ⛶ (справа сверху) для полноэкранного сравнения обоих видео, кнопку переключения вида (слева сверху) — чтобы показать только одно видео.
5. Скопировать готовый Mod Note кнопкой «Copy» под нужным видео.
6. Нажать 🔗, чтобы скопировать ссылку с текущим состоянием обоих видео — её можно отправить кому угодно, и по клику откроется точно та же картина: те же видео, время старта и (если было зафиксировано) финиша, тот же FPS.

## Известные ограничения

- **YouTube**: Google в 2021 году официально отключил `getPlaybackQuality`, `setPlaybackQuality` и `getAvailableQualityLevels` в iframe API — эти вызовы ничего не делают. Ни прочитать, ни задать качество или точный FPS через API нельзя, это ограничение самой платформы, а не проекта.
- **Twitch**: список качеств (`getQualities()`) иногда приходит не сразу после `READY` — страница делает несколько повторных попыток, но если стрим только что запущен, качества и FPS могут появиться с небольшой задержкой.
- Автоопределение FPS для локальных файлов (`requestVideoFrameCallback`) поддерживается не всеми браузерами — лучше всего работает в Chrome/Edge.
- Ссылка «Поделиться» хранит только YouTube/Twitch — локальный файл переслать нельзя (в браузере нет доступа к чужому диску), для него в ссылке просто не будет данных этого видео.
